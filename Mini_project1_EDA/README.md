# Mini Project 1: Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project performs an exploratory data analysis on a customer analytics dataset.  
The dataset contains information about customer demographics, income, spending behavior, and online activity.  
The goal is to uncover patterns, clean the data, and generate actionable insights.

## 📁 Files in this repository
- `MiniProject1_EDA.ipynb` – Main Jupyter notebook with step‑by‑step analysis.
- `customer_analytics.csv` – Raw dataset used for the analysis.
- `eda_script.py` – Standalone Python script that replicates the EDA (generates plots and summary).
- `dataset_summary.txt` – Text file containing a summary of the cleaned dataset.
- `README.md` – This file.
- *Optional PNG files* – Generated plots (e.g., age histogram, correlation heatmap) – can be regenerated by running the script.
